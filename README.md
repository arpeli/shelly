# Shelly

A simple, love-themed static website for saving poems and letters for Michelle ("Shelly").

## Run locally

Open `/home/runner/work/shelly/shelly/index.html` in your browser, or serve the folder:

```bash
cd /home/runner/work/shelly/shelly
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
